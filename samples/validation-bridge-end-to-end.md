# Validation Bridge Samples

## FluentValidation

- `validation-bridge-fluentvalidation-from-rules.md` - Build validator from rule descriptors.
- `validation-bridge-fluentvalidation-from-spec.md` - Build validator directly from `ISpecification<T>`.
- `validation-bridge-fluentvalidator-class.md` - Use specification-derived validator in an `AbstractValidator<T>` class (`Include(...)` + `RuleFor(...)`).

## DataAnnotations

- `validation-bridge-dataannotations-from-rules.md` - Build artifacts from rule descriptors.
- `validation-bridge-dataannotations-from-spec.md` - Build artifacts directly from `ISpecification<T>`.
- `validation-bridge-dataannotations-class.md` - Use specification-derived artifacts in an `IValidatableObject` class implementation.
